# Statistical Machine Learning Projects

This repository contains notebooks and datasets for statistical machine learning projects and exploratory data analysis.

## Notebooks

- `BAD702 Module 1 EDA SML- Diabetes.ipynb` — Diabetes dataset
- `BAD702_Module1_EDA SML_Housing.ipynb` — Housing dataset
- `BAD702_Module_1_EDA_SML_Iris.ipynb` — Iris dataset
- `BAD702_Module_1_EDA_SML_titanic.ipynb` — Titanic dataset
- `SML_Project_AQI_FINAL.ipynb` — AQI project

## Data and report

The repository includes CSV files for the Diabetes, Housing, Iris, and Titanic datasets, as well as `sml report.pdf`.

## Running the notebooks

1. Install Python and Jupyter Notebook.
2. Install any additional Python packages imported by the notebook you want to run.
3. Open a terminal in this repository folder and run:

   ```bash
   jupyter notebook
   ```

4. Open a notebook in your browser and run its cells from top to bottom.

Some notebooks may expect their CSV files to be in the repository folder. If a notebook cannot find a dataset, check its file path and make sure you started Jupyter from the repository folder.
